# Лабораторная работа №3 — Сборка встроенной системы Linux для архитектуры ARM

Репозиторий содержит результаты выполнения лабораторной работы по конфигурированию, кросс-компиляции и запуску Embedded Linux системы под архитектуру **ARMv7** (эмулируемая плата `vexpress-a9`).

## Выполненные этапы работы:
1. Конфигурация и компиляция загрузчика первого этапа **U-Boot** (`vexpress_ca9x4_defconfig`).
2. Кросс-компиляция стабильного ядра Linux (версия **7.2.9**) под ARM (`vexpress_defconfig`).
3. Сборка автономного инструментария **BusyBox** в статическом режиме и подготовка **RootFS (initramfs)**.
4. Успешный сопряженный запуск всех компонентов в эмуляторе **QEMU**.

## Файлы в коммите:
* `lab3_report_rejep.pdf` — Полный академический отчет со всеми скриншотами и подробным разбором этапов канонической последовательности загрузки: **Загрузчик -> Ядро -> initramfs -> rootfs**.
* `busybox/_install/etc/init.d/rcS` — Созданный скрипт автоматического монтирования виртуальных файловых систем при старте ядра.
